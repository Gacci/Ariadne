MATHEMATICAL MODEL

Unified Markov-Chain Ranking

A conceptual extension of graph-based ranking for query-dependent investigative relevance.

Transition Probability

Let \(P_{ij}\) represent the probability of transitioning from entity \(i\) to entity \(j\).

Pij = d(αGij + βRij + γEij + δTij + εSij + ζAij) + (1−d)Zj

The individual components represent different dimensions of investigative relevance.

Model Components

Symbol Component Concept
Gij Graph Structure Structural importance and connectivity.
Rij Query Relevance How closely the relationship answers the current question.
Eij Evidence Strength Quality and corroboration of supporting evidence.
Tij Temporal Relevance Relevance based on timing and temporal proximity.
Sij Source Trust Reliability of the source supporting the relationship.
Aij Anomaly Signal Unexpected or missing relationships and behavior.
d Damping Factor Controls graph propagation versus teleportation.
Zj Trust Teleport Personalized probability distribution over trusted targets.
α...ζ Weights Relative importance of each feature.

Stochastic Constraint

For the matrix to represent a valid Markov process, transition probabilities must be normalized:

Σj Pij = 1

In an implementation, the feature combination would therefore need to be normalized before or during construction of the transition matrix.

Query-Dependent Transition Matrix

Unlike conventional static graph ranking, the transition matrix would be conditioned on the current investigation.

P = P(Q, C, E, T)
  • Q = investigative query
  • C = case context
  • E = evidence characteristics
  • T = temporal context

Consequently:

Ranking(Query A) ≠ Ranking(Query B)

even when both queries operate over the same underlying graph.

Trust Teleport

The teleport component provides an opportunity to introduce investigator context and source trust into the random walk.

Instead of assuming a uniform teleport distribution, the system could construct:

Zj = f(SourceTrustj, EvidenceTrustj, InvestigatorContextj)

Potential teleport targets could include:

  • Verified evidence
  • Authoritative records
  • Trusted sources
  • Confirmed case entities
  • Investigator-selected entities

The exact definition of trust is an open research question. Trust should not be treated as absolute truth.

Anomaly / Negative Evidence

Traditional graph analysis primarily operates on relationships that exist. This model explores whether deviations from expected behavior can also contribute to ranking.

A(v,Q) = ExpectedBehavior(v,Q) − ObservedBehavior(v,Q)

For example, a communication pattern that normally occurs frequently may disappear during a critical period.

However, an observed absence may have multiple explanations:

  • The relationship genuinely did not occur.
  • The relationship occurred but was not recorded.
  • The relevant data source is incomplete.
  • The collection system failed.
  • The behavioral baseline is incorrect.
Anomaly should be treated as an investigative signal, not evidence of guilt.

Dynamic Weight Learning

The coefficients α, β, γ, δ, ε, and ζ could initially be specified by domain experts.

A later version could learn the weights from labeled cases.

Three possible strategies

A. Expert Weights

Domain experts specify the relative importance of each feature.

B. Global Learning

A single set of weights is learned from historical or synthetic cases.

C. Query-Dependent Learning

The system learns weights as a function of the investigative question and case context.

A pairwise learning-to-rank objective could, for example, attempt to ensure:

Score(relevant) > Score(irrelevant)

The appropriate learning strategy remains an experimental question.

Potential Extensions

  • Temporal Markov models
  • Dynamic graphs
  • Bayesian evidence modeling
  • Contradiction detection
  • Multi-source corroboration
  • Counterfactual ranking
  • Investigator feedback
  • Adaptive query interpretation

Important Boundary

The mathematical score should represent investigative relevance, not probability of guilt.

A score of 0.91 should not mean "91% probability this person committed the crime."

It should instead mean something closer to:

Under the current query, evidence, temporal context, and ranking model, this entity has a high computed relevance.
