PRIOR ART / COMPARISON

How Does This Compare?

The individual technologies behind this concept are not new. The research question concerns their combination and interaction.

A Deliberately Conservative Claim

This project does not claim to have invented:

  • PageRank
  • Personalized PageRank
  • Knowledge graphs
  • Link analysis
  • RAG
  • Large Language Models
  • Anomaly detection
  • Learning-to-rank
  • AI-assisted investigations

Many of these technologies have already been applied independently or in combination in search, cybersecurity, fraud detection, intelligence analysis, and investigative environments.

The question being explored here is narrower:

Can these ideas be integrated into a unified, query-dependent, evidence-aware Markov ranking architecture specifically designed around investigative relevance?

Traditional Link Analysis

Link-analysis platforms are highly effective at showing relationships, networks, timelines, and organizational structures.

Strength

Excellent at visualizing and exploring relationships.

Challenge

Large networks can contain more relationships than an investigator can reasonably examine.

The proposed idea emphasizes a ranking layer that dynamically prioritizes relationships according to the investigator's current information need.

PageRank and Personalized PageRank

PageRank established the importance of graph structure in ranking. Personalized PageRank further demonstrated that graph importance can be conditioned on a preference or personalization vector.

Therefore:

Using PageRank or Personalized PageRank in an investigative graph is not itself a novel claim.

The proposed research instead explores extending this family of approaches with additional investigative features such as:

  • Semantic query relevance
  • Relationship semantics
  • Evidence strength
  • Temporal relevance
  • Source trust
  • Anomaly signals
  • Alternative explanations

Knowledge Graphs

Knowledge graphs are already widely used to represent entities, relationships, attributes, and provenance.

Their strength is representing complex relationships and supporting multi-hop queries.

This project treats the knowledge graph as the computational substrate over which a dynamic relevance-ranking process operates.

RAG

Retrieval-Augmented Generation can retrieve documents and evidence relevant to a natural-language query.

However, semantic retrieval alone does not necessarily capture:

  • Graph centrality
  • Relationship direction
  • Multi-hop network structure
  • Temporal sequences
  • Expected-but-missing relationships
  • Network-wide propagation

In this architecture, RAG would therefore function primarily as an evidence retrieval and grounding layer.

LLM-Based Systems

LLMs can already perform tasks such as:

  • Natural-language question understanding
  • Entity extraction
  • Relationship extraction
  • Document summarization
  • Semantic classification
  • Graph-query generation
  • Explanation generation

The proposed architecture intentionally avoids making the LLM the sole ranking authority.

The ranking should remain grounded in explicit graph and evidence features that can be inspected and evaluated.

Comparison

Approach Primary Strength Potential Limitation

PageRank Graph-based importance Basic ranking is not inherently evidence-aware
Personalized PageRank Query/context personalization Still requires appropriate personalization signals
Link Analysis Relationship discovery Large networks can produce information overload
Knowledge Graphs Complex relationship representation Representation alone does not determine investigative priority
RAG Semantic evidence retrieval Does not inherently model network propagation
LLM Language understanding and explanation Can be difficult to make ranking deterministic and auditable
Proposed Architecture Combines graph, query, evidence, time, trust, anomaly, and retrieval Requires substantial empirical validation

Where the Potential Contribution Lies

The proposed contribution should therefore be stated cautiously. It is not:

"Nobody has done this before."

A more defensible formulation is:

"The project investigates whether a unified, query-dependent Markov ranking architecture can combine graph structure, semantic relevance, evidence strength, temporal context, source trust, anomaly signals, and provenance to improve investigative information prioritization."

The contribution would ultimately need to be demonstrated experimentally.

Open Questions

Several important questions remain unresolved:

  • How should evidence strength be quantified?
  • How should source trust be defined without introducing systemic bias?
  • How should missing information be distinguished from genuine absence?
  • How should weights be learned?
  • Can anomaly signals improve ranking without increasing false positives?
  • Can the approach outperform simpler baselines?
  • How should investigator feedback affect future rankings?

These questions are part of the research rather than problems to be hidden.
